API de Autenticação e Gestão de Utilizadores

Backend desenvolvido em Java com Spring Boot para o sistema de autenticação e gestão de utilizadores da aplicação **Amigo da Vizinhança**.

Tecnologias Utilizadas

* **Java 17+**
* **Spring Boot** (Spring Web, Spring Security, Data JPA)
* **PostgreSQL / MySQL**
* **Maven** (Gestão de dependências)

 Funcionalidades

* [x] Registo e cadastro de novos utilizadores
* [x] Autenticação e login com verificação de credenciais
* [x] Encriptação de passwords (BCrypt)
* [x] Controlo de acessos e permissões de segurança

Como Executar o Projeto Localmente

### Pré-requisitos
* Java JDK 17 ou superior instalado
* Maven instalado (ou utilizar o wrapper `./mvnw`)
* Banco de Dados configurado

1. **Clonar o repositório:**
